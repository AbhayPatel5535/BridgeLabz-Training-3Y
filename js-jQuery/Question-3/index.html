Frequently Asked Questions

Click a question to read its answer. Double-click any question to close all answers.

1. What is jQuery?

jQuery is a JavaScript library that makes DOM manipulation and event handling easier.

2. What is a selector?

A selector finds HTML elements so that jQuery can work with them.

3. What does hide() do?

The hide() method hides the selected elements from view.

4. What is an event?

An event is an action such as a click, hover, key press, or form submission.

5. What does toggle() do?

toggle() switches an element between visible and hidden states.
